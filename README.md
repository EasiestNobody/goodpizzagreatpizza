## 📖 About The Project

**Good Pizza, Great Pizza** is a vibrant, cozy, and playful pizzeria web platform themed around the aesthetic and heart of the popular cooking simulation game. Set in the mountain breeze of **Baguio City, Philippines**, this web app delivers a delightful ordering experience with tactile animations, hand-drawn game vibes, customizable drink add-ons, and real-time promo tracking.

---

## ✨ Features & Gameplay Vibe

### 🍕 Interactive Pizza Showcase & Details Modal
- Browse 7 handcrafted specialty pizzas with prices, flavor tags, and custom artwork.
- Click any pizza card to view a high-resolution detail modal with ingredients and description.
- One-click **Add to Cart** with animated confirmation feedback.

### 📅 Dynamic Weekly Promos (Real-Time Day Highlighting)
- Automatically checks the current day of the week and highlights **TODAY's active promo deal** with a dedicated glowing badge and custom styling.
- Daily deals include *Meaty Monday*, *Cheesy Tuesday*, *Whopper Wednesday*, *Thirsty Thursday*, *Flavorful Friday*, *Savory Saturday*, and *Slice Sunday*.

### 🥤 Pair Your Pizza (Drinks & Add-ons)
- Complement your pizza order with refreshing beverages and desserts (Classic Cola, Sundae Delight, Fresh Lemonade, Iced Tea, Mango Shake, Mineral Water).
- Quick `+` button with instant visual feedback and toast notifications.

### 🛒 Real-Time Cart & Floating Action Button (FAB)
- Dynamic cart summary that tallies total bill in Philippine Peso (`₱`).
- Floating Cart Button (`FAB`) with live item counter that appears whenever items are added to the cart.
- Individual item removal and instant price recalculation.

### 📝 Seamless Delivery Checkout
- Complete order form with customer name, Baguio delivery address, special cooking instructions, and payment method selector:
  - 💵 **Cash on Delivery (COD)**
  - 📱 **GCash**
  - 💳 **Maya**
- Interactive Order Success modal summarizing order items, delivery location, and grand total.

### 💫 Delightful Micro-Animations
- Floating topping particles (`🍕`, `🧀`, `🍅`, `🌿`, `🫒`, `🥓`) drifting across the hero banner.
- Scroll-triggered reveal effects powered by `IntersectionObserver`.
- Rotating pizza showcases, hovering cards, button bounce effects, and custom animated toast notifications.

### 📦 Game-Inspired Eco Packaging
- Showcases the custom cartoon-style packaging, eco-friendly recyclable materials, heat-retention layer, and unboxing experience.

## ⌨️ Keyboard Shortcuts

Speed up your navigation across the pizzeria using handy hotkeys! When you're not typing into a form field, press any of the following keys:

| ⌨️ Key | 🎯 Action | 📍 Destination / Effect |
|:---|:---|:---|
| <kbd>M</kbd> | **Jump to Menu** | Smooth scrolls to the Pizza Menu section |
| <kbd>P</kbd> | **Jump to Promos** | Smooth scrolls to the Weekly Deals & Promos section |
| <kbd>D</kbd> | **Jump to Drinks** | Smooth scrolls to the Drinks & Add-ons section |
| <kbd>C</kbd> or <kbd>O</kbd> | **Jump to Cart / Order** | Smooth scrolls straight to the Order & Checkout section |
| <kbd>L</kbd> | **Jump to Location** | Smooth scrolls to the Baguio City store address & map info |
| <kbd>H</kbd> | **Jump to Home** | Smooth scrolls back to the top Hero section |
| <kbd>Esc</kbd> | **Close Modal** | Closes any open Pizza Detail or Order Success modal |
| <kbd>?</kbd> | **Help Toast** | Displays a quick overlay toast with all available shortcut keys |
| <kbd>Tab</kbd> / <kbd>Shift + Tab</kbd> | **Accessible Focus** | Cycles through interactive elements, buttons, and form inputs |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | **Select / Trigger** | Activates focused buttons, opens cards, or submits forms |

## 🛠️ Technologies Used

### 🌐 Frontend & Core
- **HTML5**: Semantic document structure, SVG icon integration, accessible forms, meta SEO tags.
- **CSS3 (Vanilla)**:
  - Custom CSS Design System (`--dough`, `--sauce`, `--cheese`, `--olive`, `--text-dark`).
  - CSS Grid & Flexbox responsive architecture.
  - CSS Keyframe animations (`pizzaFloat`, `spin`, `pulse`, `stagger`).
  - Frosted glassmorphism navigation with dynamic scroll blur effect.
- **JavaScript (ES6+)**:
  - Dynamic DOM rendering from structured JavaScript data objects.
  - State management for shopping cart calculation, unique instance identifiers, and dynamic badge updates.
  - `IntersectionObserver` API for smooth viewport scroll reveal animations.
  - Custom keyboard event listeners for quick hotkey navigation.
  - Real-time `Date().getDay()` lookup to highlight the active daily promo.

### 🎨 Typography & Design Assets
- **Google Fonts**:
  - [`Fredoka One`](https://fonts.google.com/specimen/Fredoka+One) — Playful, puffy headline typography matching the game aesthetic.
  - [`Nunito`](https://fonts.google.com/specimen/Nunito) — Clean, modern, highly legible sans-serif for UI elements and descriptions.
  - [`Pacifico`](https://fonts.google.com/specimen/Pacifico) — Expressive handwritten script for tags and slogans.
- **Icons & Graphics**:
  - Custom SVG vector icons for sharp scaling at all DPI resolutions.
  - High-res themed pizza, drinks, packaging, and location artwork.

## 🚀 Getting Started

Follow these steps to run the project locally on your machine:

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/EasiestNobody/Good_Pizza_Great_Pizza.git
cd Good_Pizza_Great_Pizza
```

### 2️⃣ Run the Website
Since this project uses pure vanilla web technologies, you can run it using any static server or directly in your browser:

- **Option A (Direct File)**: Double-click `index.html` to open it in your default web browser.
- **Option B (VS Code Live Server)**: Right-click `index.html` and select **"Open with Live Server"**.
- **Option C (XAMPP / Apache)**:
  1. Move the folder to your XAMPP web root: `C:\xampp\htdocs\Good_Pizza_Great_Pizza`
  2. Start Apache from the XAMPP Control Panel.
  3. Navigate to `http://localhost/Good_Pizza_Great_Pizza` in your browser.
